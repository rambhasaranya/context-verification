# Evidence-Aware Detection and Verification of Misleading Context in Multimodal Video Posts

## About

This project aims to verify whether the context or claims associated
with a video are supported by available evidence.

## Project Flow

Video/Claim
↓
Claim Analysis
↓
Evidence Retrieval
↓
Verification
↓
Supported / Conflicting / Insufficient
